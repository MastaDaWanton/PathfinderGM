Pathfinder GM

← back to the shelf build {{ build }}

A Pathfinder 1st Edition game you play like a story. A language model on your own machine narrates and plays everyone who is not you; a rules engine owns every number, every condition and every die. Nothing leaves your computer.

What you need

Windows, and Ollama. Ollama is the program that runs the language model. It is free, it installs into your own account without asking for an administrator, and this app does not bundle it — partly because the models are far too large to ship inside an installer, and partly because if you already have Ollama you should keep using the one you have.

You do not have to go and find it. If Ollama is not on this machine, Settings has an Install Ollama button that fetches it and opens it for you, with a progress bar, so there is no download page to hunt through. It checks the file before it runs anything: Windows itself has to vouch for the signature, and it has to say Ollama. Then Ollama's own installer appears and you agree to it — nothing is installed quietly. The link is still there beside the button if you would rather do it yourself, and on a Mac or on Linux the link is the way.

Then the models themselves. The app fetches these for you; you never type a command.

Will it run well on my machine?

The narrator is a 12-billion-parameter model. It wants roughly 8 GB of video memory to be comfortable. With less than that Ollama will fall back to your processor and main memory, which works and is slow — minutes per turn rather than seconds. You will also want about {{ disk_wanted }} free on whichever drive Ollama keeps its models on.

How fast is a turn, honestly? On a machine with a recent graphics card, roughly fifteen seconds — sometimes forty when the turn is complicated. The first turn after you start the app is slower, often close to a minute, because the model has to be read into memory once; after that it stays loaded.

This is the price of the whole thing running locally, with no account, no subscription and nothing sent anywhere. It is a real cost and it was chosen deliberately. Most of a turn involves no model at all — every roll, every modifier and every condition is decided by code, instantly — so the wait is the writing, not the rules.

If you would rather not run a model locally, Settings lets you point any of the four jobs at a hosted provider with an API key instead. Local is the default and always will be; it is not compulsory.

The first run

  1. Install Ollama and start it.
  2. Open Pathfinder GM and go to Settings. The top section says what is missing.
  3. Press Download beside the model it names, and wait. There is a progress bar; you can leave the page open and come back.
  4. When it finishes, the warning disappears and you can start a game.

Until that is done the app will not open the table — it would only be able to show you an error where the story should be. Everything that does not need a model stays open the whole time: making a character, the crafting benches, and all the homebrew editors.

Worlds

This app does not invent the world. It plays inside one written by World Bible, a separate program that generates a complete setting — its peoples, its towns, its factions, its history — and exports it as a single file.

{{ shipped_worlds }} {{ shipped_verb }} with the app, so you can play straight away. To add your own, export one from World Bible and press Import a world on the shelf. The file is read and checked as it lands, so a world this build cannot play is refused there and then rather than halfway through a session.

The world file is never written to. Everything your game changes — a dead merchant, a burned bridge, a warrant out for your arrest — lives in your campaign save instead, so the same world can host several campaigns and re-exporting it never damages one.

Your character

Full 1st Edition character creation, with the rules enforced as you go: {{ classes }} classes, {{ races }} races, {{ feats }} feats and a point-buy spread that the app checks rather than trusts. Press Create a character.

Or take one of the ready-made characters on the shelf if you would rather start playing than start building.

Where you were before

You may also pick a background: {{ backgrounds }} backgrounds ship, in groups like the trade, the road and the law. A background is not a personality quiz — it names somebody in this world who already knows you. Pick Apprenticed and, once your world is chosen, the game decides which trader you served under and where, and says so in the first paragraph you read.

Backgrounds grant standing, not power: at most two skill points, in a bonus type of their own so they never stack into something a feat would charge for. What they really give you is a door you can walk through without explaining yourself. It is optional — a character with no past is a perfectly ordinary way to arrive.

After the build comes outfitting: your starting gold, spent on real equipment at real prices, before anybody opens a door. You level up from the sheet when you have the experience, all the way to 20th.

You play one character. Everyone else in the world — allies, hirelings, enemies, the person behind the counter — belongs to the GM. The dice popup only ever asks you for your own rolls.

Playing

Type what you do, in your own words, into the box at the bottom. "I ask the stallholder who owns the mill." "I follow the road north." "I look behind the curtain." The GM answers in prose and the engine resolves anything mechanical inside it.

Above the box there are usually two or three suggestions — things you could plausibly do next. They are a shortcut, never a menu: anything you can type is allowed, and the suggestions are only there so you are never staring at an empty box.

The dice

When something you did needs a roll, a die appears and you roll it. Every modifier that went into the total is itemised beside it, so you can always see why the number is the number. Rolls that are not yours — an enemy's attack, a guard's Perception, a hidden check — are made by the engine and never shown to the GM before they happen.

This is the arrangement the whole app is built around: the GM proposes and the engine disposes. The narrator can say a blow is struck; only the rules decide whether it landed and for how much. It cannot talk the game out of its own rules, because it is never asked.

Who is behind the counter

{{ keepers }} kinds of place sell something or do something for money — a smithy, an inn, a tannery, a harbour, a gaol — and each one has somebody in it. They are not invented as you walk in. The name is drawn from the families the world itself wrote in that settlement, so the smith in a town is one of that town’s own people; the choice is fixed by the place, so it is the same smith when you come back next week; and the numbers come from the stat block the game picked for the job, which you can correct on the NPCs bench like anything else.

They belong to the room and not to you. Walk out and they stay behind their counter, still there when you return — and if something happens to them, it has happened. Nobody new appears to take over a shop whose keeper you killed.

Things that start without you

The world has {{ quests }} quest lines in it, and none of them waits to be accepted. A debt in a ledger, a sickness in a village, something taking the herds: each one looks for a place and a person that suit it, and opens where it fits — so the trader who owes money is a trader this world actually has, standing where the world put them.

You are never told that a quest has begun, because nobody in the world would say so. You hear about it the way you would hear about anything: somebody mentions it, a letter finds you, a crier says it in the square. Walking away is an ending like any other, and the world goes on having the problem.

Leaving town

You are not stuck in one place. Where the world has written a road between two settlements you can take it, and it costs days — the clock moves, you camp on the way, and whatever was happening behind you carries on happening. Anyone who is not coming is left where they stood.

How long a road takes depends on how fast you walk and what you are walking over. If the world said how far it is, the rules do the arithmetic; if it did not, the game tells you how many days it took and does not invent a distance nobody wrote down. Some settlements have no road written to them at all, and it will say so rather than pretending.

Time, food and rest

Your sheet tracks thirst, hunger and rest, and the world's clock runs whether you are watching or not. Resting, eating and travelling all take real time, and the people around you get on with their own business in it.

A wait of a day or more (a bench's Wait for it, or "I wait three days") is lived through on what you carry: a day's water (a gallon, which is two waterskins) and a day's food (a pound, which is one trail ration) as each comes due, and a night's sleep. The result says what it cost. If your pack runs out first, the wait stops before thirst or hunger can hurt you and says why; the work keeps, and you can come back to it.

Fights

When a fight starts you get initiative, a turn order, and a panel of what you can actually do this turn: Strike, Full attack, Ability, Cast, a swift action, a free action. Pick a target and commit the turn.

Some scenes also carry a map — a five-foot grid you can move on by clicking a square. Where there is one, reach, cover, charge lanes and attacks of opportunity are measured from real distance rather than asserted. Where there is not, the same three ranges — engaged, near, far — are tracked without one.

Up and down

A room is not flat. Most places are built with something to climb — a gallery, a landing over the hall, the wall-walk above a gate, ground that rises — and the map has a level to look at, so you can see who is up there and stand on it yourself. Somebody on another floor of the same room is faded rather than hidden; they are still there.

Height is worth something. Swinging down at somebody is worth +1, though shooting down at them is worth nothing — that is the rule, not an oversight. A rail along a gallery is cover for both of you and stops neither. A thing with a climb speed, like a spider, is dangerous on a wall in a way a person climbing one is not, and a flier indoors only has as much air as the ceiling leaves it. You cannot get up somewhere without a way up, and the game will say which you are missing.

Buildings have floors, reached by their stairs and only by their stairs. A fireball is a sphere — it has a top, so a flier high above one is genuinely out of it.

Seeing the board

The map draws two ways, and the button above it says which. Flat is the grid from overhead. 3D is the same board seen from a corner, with the raised parts actually raised — the gallery stands above the hall rather than being a differently coloured square. The two arrows beside the button turn the board a quarter at a time, so whatever is hidden behind a pillar can be looked at from the other side. Four fixed corners rather than a free spin: a tactical board you can point anywhere is a board you lose your place on.

Both views are the same map. A square you can click in one is a square you can click in the other, and clicking it queues the same move — nothing in the 3D view is decided anywhere else, and nothing in it is decoration. The ⤢ button opens either view at a size you can actually plan a turn on.

Reading it without textures. There is one lamp, high and to your left, and it belongs to the room rather than to the board — so when you turn the board the lit side stays the side the light is on, and the shape of a thing is told by which of its faces are bright. A box is something solid. A thin standing rail is a thing to shoot over, and it stands through exactly the heights it blocks: a shot under its top is stopped and a shot over it is not. Your own party is gold, foes are red, allies green, bystanders white — the same four colours the flat map uses. Squares you can reach this turn are washed gold over whatever the ground already is.

A floor over your head is drawn through. Pick a level with Looking at and anything higher — a gallery, a landing — goes translucent so you can see yourself and the fight underneath it. Walls never do that, however you are looking: a wall is a wall from every level, and a transparent one would be telling you that you have a shot you do not have. A figure standing on a level you are not looking at is drawn faint; it is still there, and it can still see you.

Conditions, buffs, durations, iterative attacks, manoeuvres, damage reduction, resistances and stacking rules are the engine's business and are applied whether or not anybody mentions them. {{ spells }} spells and {{ creatures }} creature stat blocks are loaded and available to it.

Asking questions, and cheating

Two things you can type that are not your character speaking. Both start with a slash, so no ordinary sentence can be mistaken for one.

What you typeWhat happens
/gm who runs this town? Answered out of character, from the world's own material and the state of your game — not made up. Answers read off the engine or the books are labelled differently from answers the model had to reason its way to, so you can always tell a fact from an opinion.
/cheat I have 1000 gold You become the author for one line. Use it to fix something that went wrong, or to skip past something you do not want to play out.

Neither goes into the story. The narrator never sees the question or the answer, so it cannot quietly turn one into a fact about the world on the next turn.

The benches

Crafting. {{ disciplines }} — each with its own materials, recipes, and the gathering that feeds it. Reachable from the shelf or from the table.

How every craft levels

Each craft is a track of its own beside your class: an Herbalist, a Blacksmith, an Alchemist, a Leatherworker, an Enchanter. It grants no hit points or saves. It levels on the work you do at its bench, and the levels open new methods and rarer materials up to level 3. Past that the levels never stop, and each one gives you two perk picks.

Mastery. Every step that succeeds pays mastery: 1 for the step, 1 more for each band of rarity above common, 1 more for Superior work and 2 for Flawless. A batch pays for every dose in it. A first time (a new property learned, a new kind of product) pays 3, and reading a craft manual you have not read pays 5. Studying a material pays 1 for each property it turns up. A failure teaches a little, twice, and then nothing more.

What a level costs. Level 2 costs 100 mastery, level 3 costs 260, and every level after that costs 400. Enchanting keeps its own, gentler curve: 25, then 65, then 50 for level 4 and 10 more each level after. Levels you have already earned are kept. The /gm door tells you exactly where you stand: ask it "what do I need for the next forge level".

Long steps. Any step of an hour or more goes In Progress: you set it going, the bench shows it working, and it is ready when the clock reaches its time. You need not stand over it.

Beating the check. Beat a craft or harvest check by 5 or more and everything goes better: more comes out, it takes less time, and the quality cannot fall as low. A natural 20 lets the work break through your quality ceiling.

Herbalism

Herbalism is worked at the table, one step at a time: pick a method, put what you carry on the tool, roll your Craft check, then play the short game that decides how good the result is. What a step makes goes back in your satchel, ready for the next step.

Grind (Herbalist 1)A herb into powder. Bark, sap and resin grind into a salve base.
Mix (1)A ground herb into a poultice (water binds it), salve bases together, or a base with infused oil into a salve or balm, or with an infusion into a cream.
Brew (1)Leaves and flowers into an infusion, roots, bark and berries into a stronger decoction.
Dry (2)Two of a solid into one, half again as strong and as long lasting.
Reduce (2)Two of a liquid simmered into one, half again as strong.
Extract (2)A part out of its shell, gland or pod. Some things must be extracted before anything else.
Infuse (2)A dried herb into oil, one oil a dose. Infused oil is sold or mixed into salves.
Steep (2)A herb in spirits (a tincture, ready in two weeks) or vinegar (an acetum, ready in one). The jar travels with you and is ready on its day.
Neutralize (3)Makes a volatile thing safe to work, one neutralizer a dose. Until you know it, a volatile herb cannot be ground.

The roll. Your Craft check is d20 + your Herbalist level + half your character level + Wisdom, against the DC shown before you roll. A bench check has no automatic 20 or 1: if no roll can make it, the bench says how much more you need. Miss by 4 or less and you lose only the time. Miss by 5 or more and half of what was on the bench is ruined.

Quality. The game after a good roll sets the quality: Crude, Sound, Fine, Superior, Flawless, and past that Flawless +1 and on. Your level sets the best you can reach (Fine at Herbalist 1, Superior at 2, Flawless at 3, more with Quality perks). Better work is stronger, lasts longer, has milder drawbacks and sells for more. A poor game never costs you materials.

Batches. Make many at once with one roll and one game: the whole batch shares the result, and the time grows with its size.

Concentrating. Dry and Reduce can be repeated as long as you have two of a thing. Each step is rarer and harder than the last, so a deep concentrate is a master's work.

What a remedy can carry. A form carries only what works the way it is taken: a tea what is swallowed, a poultice what works in a wound, a salve or cream what works on the skin or the eyes. Anything that reaches outside the body, like invisibility, is alchemy and is left out.

The forge

Smithing is worked at the anvil, one step at a time: pick a method, put what you carry on the anvil, roll your Craft check, then play the short game that decides how good the result is. Every step puts a real thing on your rack, an ingot, a bar, a blank, a plate or a finished item, ready for the next step. A weapon goes smelt, alloy, forge, quench, temper, fold or hone, assemble, finish; you can stop at any step and pick up later.

Smelt (Blacksmith 1)Two ore and two fuel into one ingot, in a smithy's furnace. A flux in the charge carries off the slag of dirty ore. Exotic or legendary ore needs a fuel of rare tier or better.
Forge (1)Bars and fuel into a blank for a weapon or a plate for armour or a shield, in the shape you pick from the weapon and armour lists. Bigger things take more bars.
Quench (1)A hot blank or plate into a bath to harden it. The bath leaves its mark on the metal, and leaves it brittle until it is tempered.
Assemble (1)The pieces into the finished item: head, haft and fittings for a weapon; body, fastenings and lining for armour. The first two are needed, the third is optional. The main piece counts in full, the others half.
Assay (1)Tests a sliver of a material to learn what it does. Worked from the material's card, not the anvil.
Alloy (2)Ingots or bars of two or more metals melted together into a named alloy: steel (iron and carbon), bronze, brass and rarer ones. Melting undoes any strengthening.
Temper (2)Takes the brittleness out of a quenched piece.
Fold (2)Doubles a bar or piece over itself. It drives the slag out of dirty metal; on clean metal it adds a little hardness. A steel bar folded with a high-carbon steel bar makes pattern steel.
Hone (2)Puts the edge on a slashing or piercing weapon blank.
Strengthen (2)Two bars of one metal welded into one. Everything the metal carries, good and bad, counts half again as much. It can be done again.
Finish (2)A treatment on a finished item's surface: bluing, etching, plating, silvering. Holy anointing, ghost-salt blanching and oblivion water need Blacksmith 3.

The roll. Your Craft check is d20 + your Blacksmith level + half your character level + Intelligence + half your Craft ranks, against the DC shown before you roll. Forge and Assemble use the book's DC for the item: simple weapons 12, martial 15, exotic 18, armour and shields 10 plus their armour bonus. Other steps use the material's own DC, higher for rarer metal. A bench check has no automatic 20 or 1: if no roll can make it, the bench says how much more you need. Miss by 4 or less and you lose only the time. Miss by 5 or more and half of what was on the anvil is ruined, the cheaper things first.

Quality. The game after a good roll sets the quality: Crude, Sound, Fine, Superior, Flawless, and past that Flawless +1 and on. Your level sets the best you can reach (Fine at Blacksmith 1, Superior at 2, Flawless at 3, more with Quality perks). A finished item can rise at most one step above its main piece. Better work makes the metal's good marks count for more and never makes its drawbacks worse.

Masterwork. Superior or better is masterwork. Before Assemble you choose whether to aim for it: aiming raises the DC to 20, and not aiming caps the item at Fine. The main piece must be tempered, and an edged blade honed, or the item cannot be Superior.

Where you work. A field kit (camp anvil, bellows, hearth, quench bucket, whetstone) works anywhere for forge, quench, temper, hone, assemble, finish and assay on common and uncommon metal. Smelt, alloy, fold and strengthen, and any rare or rarer metal, need a smithy: a town forge you pay by the hour, or one you own, which is free. A smith who dislikes you will not let you at the forge.

Rarer metal. Blacksmith 1 works common and uncommon metal, 2 rare and exotic, 3 legendary.

Alloys. Each recipe wants its metals in a share window, and the bench names the share that is off. Two metals no recipe names still pour a new alloy, named after both, if each is at least a fifth of the charge; two different metals of the same top rarity come out one band rarer. Cold iron, mithral, adamantine and the skymetals work alone and only go into a recipe that names them.

Materials and their marks. Every metal, fitting, fuel and bath has its own good and bad marks, and each piece brings its own onto the item. A bath's quench mark lands once. Finishes add their own effect and keep the book's limits: alchemical silver will not take on adamantine, cold iron or mithral, and adamantine edging and cold-iron blanching go on weapons only. Some metals change how the work goes: slaggy metal cannot reach your best quality until it is folded, malleable metal ruins nothing on a bad miss, pure metal lets you roll the check twice and keep the better, and sulfurous fuel can leave crude work hot-short.

Studying materials. An assay costs a tenth of a bar or one ore, and ten minutes, whether or not you make the roll. Its DC is 10, plus 5 for each band of rarity above common, less 1 for each other material of the same kind you know (at most 4 less). Success reveals one benefit and one drawback. Reactive metals bite back: their harm lands on you whatever the roll. Working a metal at the anvil also teaches you how it behaves, a smith will teach what they know for a fee if they like you well enough, and a library holds the benefits of common and uncommon metals.

Leather on the anvil. A leatherworker's grip can be a weapon's haft and a lacing set a suit's fastenings. Studded leather and the armoured coat are finished from a leatherworker's base, and steel lamellar must be laced with a lacing set. A suit made on a leather base is no better than its base.

Alchemy

Alchemy is worked at the bench, one step at a time: pick a method, set what you carry on the glass, roll your Craft check, then play the short game that decides how good the result is. What a step makes goes back on your shelf, ready for the next step. Most lines start with Dissolve and end with Bottle, and a bottled product never goes back in.

Dissolve (Alchemist 1)A solid in a solvent (water, spirits, vinegar, oil or acid) into a solution, which keeps three days.
Calcine (1)A solid roasted in the crucible to a calx, which keeps for ever. Anything combustible burns away instead.
Bottle (1)A liquid or a powder into a vessel. The vessel decides what you make: a vial is drunk or poured on, a clay flask thrown, a casing struck, a stick lit.
Assay (1)A pinch of a reagent (a tenth of one) tested on glass. A success shows one benefit and one drawback; a miss shows nothing, and the pinch is gone either way.
Filter (2)A liquid through cloth. Every drawback stays on the cloth as a precipitate, and the filtrate runs clean at nine tenths of its strength.
Distill (2)Two measures of a liquid into one spirit, half again as strong and as long lasting. A spirit keeps a year. Laboratory only.
React (2)Two or more inputs, one of them a liquid, into an admixture. Their traits merge, and the same trait from two materials adds its grades.
Sublime (3)Two measures of a solid into one sublimate, half again as strong and as long lasting. Laboratory only.
Transmute (3)Two of a material into one of the same kind, one band rarer, that shares an essence with it. You choose which. A day's work, laboratory only.

The roll. Your Craft check is d20 + your Alchemist level + half your character level + Intelligence + half your Craft ranks, and +2 more in a laboratory. The DC is the hardest input's own, a known formula's book DC when you bottle it (5 + caster level for a spell potion), or 10 + 5 a band of rarity for a Transmute. Each Distill or Sublime past the first adds 2. A bench check has no automatic 20 or 1: if no roll can make it, the bench says how much more you need. Miss by 4 or less and you lose only the time. Miss by 5 or more and half of what was on the bench is ruined.

Quality. The game after a good roll sets the quality: Crude, Sound, Fine, Superior, Flawless, and past that Flawless +1 and on. Your level sets the best you can reach (Fine at Alchemist 1, Superior at 2, Flawless at 3, more with Quality perks). Better work is stronger, lasts longer and has milder drawbacks; a spell potion's quality raises its caster level instead. A poor game never costs you materials.

Where you work. Common and uncommon work needs an alchemist's field kit in your pack, which you buy. Rare and rarer material, and Distill, Sublime and Transmute, need a laboratory: your own is free, a town's is rented by the hour. Nothing is worked in a fight.

Traits and grades. Everything you put in brings its traits, each distinct material once however many you use. Same-named traits add their grades, but never past your Alchemist level. A higher grade means more dice, a larger bonus, a longer condition and a save 2 harder for each grade above the first.

What a product can carry. A draught holds three benefits, an oil, flask or smoke pot two, a stick one, and a formula's core takes one of them. The rest are your pick. A draught carries what works when swallowed, an oil what works on the skin, a flask what works where it strikes; anything else is shown dimmed with the reason and left out. Drawbacks take no room and always come along, unless you filtered them out first.

Formulae. A formula is made of essences, not of named reagents: any reagent that carries fire serves an alchemist's fire. You start knowing alchemist's fire, acid, antitoxin and the tanglefoot bag. Bottle with no formula chosen and you experiment: if the mix fits exactly one formula within your reach, a success writes it into your formulary. Spell formulae can also be copied from a scroll or a spellbook (a check against DC 15 + the spell's level, and the writing cost), learned from a potion in hand (which is used up), or taught by a companion who knows the spell; an alchemist teacher or a formulary teaches any. You can bottle spells up to half your Alchemist level, at least 1st. A harmful spell in a draught takes whoever drinks it as its target.

Volatile and toxic. A volatile input flares on a miss by 5 or more, once for the batch, and you take the harm it names, shown before you roll. Each volatile input beyond the first adds 3 to the DC, and each stabilizer you add makes one of them safe. A toxic reagent hurts as the step begins, whatever the roll, unless a laboratory's fume hood or a mask and gloves protect you. Both apply to an assay too. Corrosive work cannot be bottled in metal: use glass or clay.

Catalysts. A catalyst or a piece of apparatus set beside the work is never spent and widens the game's window. Some do more: philosopher's mercury makes a Transmute one for one, and pure material lets you roll twice and keep the better.

Leatherworking

Leatherworking is worked one step at a time, from a green hide off the carcass to the finished piece: pick a method, put what you carry on the bench, roll your Craft check, then play the short game that decides how good the result is. Every stage goes back on your shelf (salted hide, pelt, leather, panels, plates), ready for the next step.

Salt (Leatherworker 1)Rubs curing salt into a green hide, one measure a hide unit. A salted hide keeps for six weeks instead of two days.
Flense (1)Scrapes a green or salted hide into a pelt, ready to tan. A thick hide must first sit three days in a tannery's lime pit.
Tan (1)A pelt and a tannin into leather, or into fur with the hair left on. With no tannin at all the hide is dried as rawhide.
Cut (1)Leather, fur or rawhide into panels for a pattern's body or lining, a lacing set or a grip. Hides of one kind and grade combine; what is left over goes back on the shelf.
Stitch (1)Cut panels into a body or a lining, with a thread.
Harden (1)Boils bark- or planar-tanned panels into hardened plates, the body of leather armour, lamellar and the madu.
Assemble (1)A body, its fastenings and a lining if you want one into the finished suit, shield, cloak, boots, bag or other good.
Grade (1)Flexes a scrap of a material (a quarter unit of hide, or one measure of a supply) to learn one thing it gives and one it costs.
Curry (2)Works an oil into tanned leather or fur until it is supple. A soft body needs it before it can be masterwork.
Tool (2)Stamps and carves the leather's face, with a wax if you have one. A body must be tooled to reach Flawless.
Dye (2)Colours a tanned piece. Mordant salts make the colour fast.
Laminate (2)Two of one leather into one heavier leather: every modifier half as strong again, the drawbacks too.

The roll. Your Craft check is d20 + your Leatherworker level + half your character level + Intelligence + half your Craft ranks, against the DC shown before you roll. A step on a common hide is DC 10, and 5 more for each step of rarity, unless the material says otherwise. Assemble uses the book's Craft DC: 10 + the armour bonus for a suit or shield, 10 for anything else. A bench check has no automatic 20 or 1: if no roll can make it, the bench says how much more you need. Miss by 4 or less and you lose only the time. Miss by 5 or more and half of what was on the bench is ruined. A masterwork kit roll you made yourself adds +2.

Quality. The game after a good roll sets the quality: Crude, Sound, Fine, Superior, Flawless, and past that Flawless +1 and on. Your level sets the best you can reach (Fine at Leatherworker 1, Superior at 2, Flawless at 3, more with Quality perks). Superior or better is masterwork.

Hide grades. Every hide has a grade, and the worst grade on the bench caps the work: grade 1 has no cap, grade 2 caps at Superior, grade 3 at Fine, grade 4 at Sound. A reject hide makes scraps only. Some tannins raise or lower the ceiling of everything made from their leather.

Masterwork at Assemble. Choose before you roll whether you aim for masterwork. Aiming raises the DC to 20; not aiming caps the piece at Fine. A soft body must be curried and plates hardened before the piece can be Superior, and a body that is not tooled stops at Superior. A hide that is masterwork by nature needs none of this. A finished piece can be at most one step better than its body.

Where you work. The leatherworker's field kit works common and uncommon hides anywhere, Harden and a bark tan included. A tannery, rented by the hour or one you own, adds the vats (mineral and planar tannages), the lime pit for thick hides, and rare and rarer hides. Your level also limits the hides you can work: uncommon at 1, exotic at 2, legendary at 3.

From hide to piece. Salt (if the beam is far off), Flense, Tan, then Curry, Tool or Dye as you wish, Cut to a pattern, Stitch the panels (or Harden them for leather armour, lamellar and the madu), and Assemble. A suit's body takes more hide for a bigger wearer. Hide armour wants a thick hide. Steel or cold-iron studs are fitted at a smith's anvil, not here.

Tannages. The tannin must be within one tier of the hide. Brain and smoke (1) is a day's bench work and needs no wait. Rawhide (1) dries in about four hours. Bark (1) soaks for about four days and sixteen hours, twice that for a thick hide, in your pack or in a rented vat if begun at a tannery. Alum tawing (2) takes about a day and more, mineral (2) half a day in a tannery's vat, planar (3) about a week in a tannery's vat. Only bark and planar leather will harden; brain, alum and mineral stay soft, and rawhide turns to glue. A salted hide soaks for eight hours first unless the tannin does not mind salt.

Freshness. A green hide spoils 48 hours after the kill. Salt stops the clock for six weeks, then it runs again. Tanned work never spoils. A spoiled hide is scraps and glue stock: it can still be graded and sold, never worked. A hide bought at a counter comes already oak-bark tanned, at grade 2.

Enchanting

Enchanting lays magic over an item someone else made. It is worked in a circle, three steps in order: prepare the vessel, attune essences to it, then bind them. Each step is a Craft check and, if it lands, a short game that decides how good the step is. Take off anything you mean to enchant first: a worn or held item cannot go in the circle.

Prepare (Enchanter 1)Lay a circle round a vessel: one chalk or salt, one ink, and at most one treatment. A ring or amulet also needs a gem set as its focus. The rarer the circle material, the harder the check, and a chalk circle holds essence one band rarer than itself.
Attune (1)Seat essences on a prepared vessel, one to a seat, and make any choices (the foe for bane, the energy for a resistance). Nothing is spent yet. An attuned vessel holds for a day; after that the essences go back to your shelf unharmed.
Bind (1)The book's creation check on an attuned vessel. The essences and any catalyst are spent and the item goes In progress for the book's time.
Read (1)Ten minutes and a tenth of a phial to learn one thing about an essence.
Identify (1)Study a magic item for what it was made to do. Once per item per day.
Unbind (1)Take the whole magic layer off an item, curse and all. The item stays as the smith made it, a quarter of the layer's motes come back as arcane residue, and you learn what kinds of property it carried, never how strong.
Refine (2)Condense two or more phials of one essence family into one fuller phial, so one seat holds more. A clean draw keeps every mote; a Crude one loses a fifth.
Cleanse (3)Lift a curse you know of and keep the rest of the magic.

The roll. Your Craft check is d20 + your Enchanter level + half your character level + Intelligence + half your Craft ranks. Only your own Intelligence counts: a headband or a spell that raises it does not reach the circle, though damage and drain do. A bench check has no automatic 20 or 1: if no roll can make it, the bench says how much more you need. Prepare, Attune and Refine are DC 5 + 5 for each rarity band of the rarest thing in them. Read is DC 10 + 5 a band, Unbind and Cleanse DC 10 + the item's caster level. Identify is DC 15 + the item's caster level, using the better of this check and your Spellcraft.

Bind's DC. 5 + the item's caster level, +5 for each spell the property needs that you neither know nor carry in a potion or scroll (a carried one is used up), +5 if your Enchanter level is below the caster level the item asks, and +5 to hurry it into half the time. A catalyst lowers it, and so does affinity (below).

A miss. A spoiled Prepare spends the circle materials; the vessel is untouched. Missing Bind by 4 or less does not take: the essences are kept and the vessel stays attuned. Miss it by 5 or more and it takes anyway, flawed, with a curse you cannot see; the item will know it is flawed, and a fragile focus cracks. Missing Refine by 5 or more ruins half the phials. Missing Unbind by 5 or more tears the layer away and loses it, with no residue and nothing learned. Any other miss costs only the time.

Quality. The game after a good roll sets the quality, from Crude up. Your level sets the best you can reach (Fine at Enchanter 1, Superior at 2, Flawless at 3), and a binding can reach at most one step above the Prepare and the Attune it was laid on. A good circle is what lets a binding reach Superior and Flawless.

Where you can work. Anywhere quiet, out of a fight: a circle on the ground will do. Refine, Cleanse and legendary essence need a sanctum, a place of your own founded as one. Somebody else's sanctum is not yours to work in.

Vessels and what they hold. A weapon, armour or shield must be Superior or better before it can carry magic, and needs at least a +1 enhancement before any special ability (+5 at most). Rings, amulets and wondrous items take no enhancement, only powers. An item holds half your Enchanter level in bonus (never less than +1), and +1 more for each quality step above Superior. Only Enchanter 2 and up can bind more than one new property at a time.

Essences and seats. Common and uncommon essence is yours at Enchanter 1, rare and exotic at 2, legendary at 3. Each essence carries motes, and a working costs motes: the seated essences must carry enough between them. Each vessel has a few named seats, and the number of seats is how many phials one working can take: a weapon has Point, Edge and Guard; armour Breast, Back and Shoulders; a shield Face and Rim; a ring Stone and Band; an amulet or cloak Clasp and Hem.

Polarity. An essence wants a kind of vessel. A weapon essence sits only on a weapon, an armour essence on armour, a shield or a wondrous item, a ward essence on a ring or wondrous item, and an essence that goes on anything goes anywhere. The wrong one is refused at Attune with the reason.

Affinity. When an essence's family suits the material its seat sits on (the blade's metal at Point and Edge, the gem at a ring's Stone), Bind is 1 easier for that seat, and at most 2 easier in all.

The hour. Each essence family has its phase of the day. Bind inside it and the game's windows are half again as wide; Wait for it moves the clock there. A few essences bind only between dusk and dawn unless the vessel was prepared with a treatment that lifts it.

Learning essences. Seating an essence shows where it sits and its hour; binding it shows what it grants; Read shows one trait more. A volatile essence bites whoever reads it, whatever the roll, with its own drawback for an hour. A missed Read still spends the pinch.

Curses. Identify that beats the DC by 10 also finds a curse. Unbind is the cheap cure: the curse goes with the whole layer. Cleanse keeps the magic, but needs Enchanter 3, a sanctum, and a curse you already know of.

Stopping a binding. Stop it while it is In progress and the item comes back as it was, but the essences are spent.

Homebrew

Homebrew. Editors for classes, races, spells, effects and consumables, plus house rules — point buy, ability ceilings, magic stacking, whether the Core races are offered at all. Anything you build here plays exactly like the shipped content, because it is the same kind of document underneath.

New versions

When a new version is out, the app says so shortly after you open it, and then waits. Nothing downloads and nothing installs unless you press something — you are asked once before the download starts, and again before the game closes to install it. If you would rather not, say so and it will not ask again until the next version.

Your characters, campaigns, worlds and homebrew are not touched by an update. They live in your own data folder, which is named on the console window behind the game, and a new version reads the same files the old one wrote.

One thing to expect, because it is better to know than to wonder: Windows will warn you when you run the installer, and it will warn you again on the next version. The app is not signed with a paid certificate, and Windows treats every unsigned file as a stranger until enough people have run that exact file. The warning is about who paid for a certificate, not about what the program does.

When the blue “Windows protected your PC” box appears, click More info, then Run anyway. That is the whole of it, once per new version.

One setting can stop it outright: Smart App Control, on some new Windows 11 machines, blocks unsigned programs with no “run anyway” at all. If the installer is refused with no button to continue, that is what happened; it is under Windows Security → App & browser control → Smart App Control, and turning it off cannot be undone without resetting Windows — which is a decision for you to make, not one this manual will make for you.

A warning on the front page about Ollama Exactly what it says. Open Settings, where the fix is a button.
"The GM could not produce a turn" The model failed every attempt at a valid turn and the app told you rather than inventing one. Try again, or rephrase what you typed. Roughly one turn in twenty needs a retry; failing outright is rarer.
