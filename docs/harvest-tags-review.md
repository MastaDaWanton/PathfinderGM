# Harvest tags: the bestiary pass, for review

Generated by `tools/harvest_tags.py` from `content/bestiary/*.json`; do not edit by hand (`--check` says whether it is stale). The owner's rule (leatherworking Q9.2): the beasts carry harvest tags and the harvest's reader (`rules/harvest.py`) finds them; the game never reads a creature's name. The names were read once, here, to propose the tags below, and every proposal is listed for review. A wrong row is fixed by adding the block to the tool's `EXCLUDE` (or a fragment to `REFUSED_FRAGMENTS`) and running it again.
