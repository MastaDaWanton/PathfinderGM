# Texture credits

Every file here is an image derived from a CC0 or public-domain source. Nothing else was
downloaded. Each was cropped, resized and recompressed, and the paper and cloth were turned
into grey detail maps that `table.css` tints with multiply blending, by `prepare_textures.py`
(which downloads nothing; the originals are not kept in the repository).
